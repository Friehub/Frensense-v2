JavaScript and TypeScript LanguageSpec implementations.

JavaScript, TypeScript and a Vue SFC’s script blocks are one language family: same AST grammar (TypeScript is a superset of JavaScript in tree-sitter-typescript), same classification, same imports and exports. The family’s LanguageSpec behaviour is therefore written once behind JsFamily, and each member states only its JsDialect — the extensions, grammar, symbol query and wrapper that actually differ.

Layout:

  • family - the one LanguageSpec implementation plus JsDialect
  • ast - shared AST classification (node → NodeRole)
  • imports - ESM/CommonJS import extraction
  • packages - npm package → PackageCategory knowledge
  • params - parameter → TaintOrigin classification
  • spec_ts / spec_js - the two family members (TypeScriptSpec, JavaScriptSpec)
  • spec_vue - the Vue SFC member (VueSpec: template blanked in place by its preprocess, script blocks parsed by the TSX grammar)

Security vocabulary (sinks, sources, sanitizers, propagators, session roots, route patterns) lives in frensense-packgen since Phase 6.3; the specs here are mechanism-only.
