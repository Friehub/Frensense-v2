Expand description

A member of the JavaScript family.

Implement this instead of LanguageSpec: the whole grammar-facing contract is provided by the blanket implementation below, and a member only names its JsDialect. Override preprocess_source when the file is a container around script code (as Vue SFCs are).

fn preprocess_source<'a>(&self, source: &'a str) -> Cow<'a, str>

Rewrite the source before parsing. Defaults to the identity.

Same contract as LanguageSpec::preprocess: the rewrite must preserve every byte offset so findings keep pointing at the original file.
