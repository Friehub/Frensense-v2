Module parse 

Source
Expand description

Source text to syntax tree, with the spec’s grammar and preprocessing.

A LanguageSpec knows which grammar a file uses and whether the source has to be rewritten first (a Vue SFC’s markup is blanked so the TypeScript parser sees only its script blocks). Both steps must happen before any role, import or query answer is meaningful, and the rewrite must preserve byte offsets. Doing that by hand means every consumer repeats:

let rewritten = spec.preprocess(&text);
let mut parser = tree_sitter::Parser::new();
parser.set_language(&spec.tree_sitter_language())?;
let tree = parser.parse(rewritten.as_ref(), None)?;

parse is that sequence once. It does not hide tree-sitter: the tree is a [Tree], its nodes are Nodes, and a caller still walks them. It removes the setup that has language knowledge in it - which grammar, and whether to preprocess - so the answer always comes from the spec.

use frensense_lang::{parse, spec_for_ext};

let spec = spec_for_ext("ts").expect("TypeScript is registered");
let parsed = parse(spec, "const id = req.query.id;\n").expect("parses");
assert!(!parsed.has_errors());
assert_eq!(parsed.text(), "const id = req.query.id;\n");

parsed.text() is the text the tree indexes into. Because the position contract in LanguageSpec::preprocess preserves offsets, those byte ranges also address the caller’s original string.
