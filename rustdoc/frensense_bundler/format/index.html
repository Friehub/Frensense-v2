frensense_bundler

Module format 

Source
Expand description

The .frc bundle: format envelope + payload types.

The bundler owns the format end to end. The engine never sees bundle bytes, it only consumes the decoded LearnedFactEntry facts, which live in frensense_engine::analysis::taint::facts.
