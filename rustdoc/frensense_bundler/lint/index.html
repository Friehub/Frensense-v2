Module lint 

Source
Expand description

Corpus lint: refuses families that would teach the engine the wrong thing.

The replay gate proves that a fact separates a family’s own pair. It cannot tell whether the pair itself is trustworthy: mislabeled, copied, duplicated, missing provenance, or only passing because the negative uses a meaningless guard. This module checks those properties before the bundler runs, so unattended authors (human or agent) cannot add a bad family quietly.

The lint reads the [frensense] block of every positive and checks it against a class registry (bug_classes.json), the file layout, provenance, cross-family diversity and, optionally, the family’s purpose against what the bare engine actually does with it - including whether the replay gate would publish any fact from the family at all, with the reason it would not, so a family that teaches nothing cannot pass lint silently.

It is self-contained: it walks the corpus with the same naming rules as extract::group_families but does not depend on FamilyMetadata, so the metadata struct can evolve independently.

Constants§

ENGINE_CLASS_IDS
The class ids the engine resolves for a sink (frensense_lang::severity:: sink_class). A learned sanitizer is scoped to its family’s class and cuts only a sink whose resolved class is in that scope, so a family whose class is not in this list teaches a sanitizer that can never cut anything.
KNOWN_KEYS
Metadata keys the lint recognises. Anything else inside a [frensense] block is reported (a typo such as serverity is otherwise silently lost).
