pub const ENGINE_CLASS_IDS: &[&str];
Expand description

The class ids the engine resolves for a sink (frensense_lang::severity:: sink_class). A learned sanitizer is scoped to its family’s class and cuts only a sink whose resolved class is in that scope, so a family whose class is not in this list teaches a sanitizer that can never cut anything.

Kept beside the lint because the registry (bug_classes.json) is corpus-owned: a corpus can define any id it likes, and nothing else checks that the engine agrees with it. The engine_class_ids_match_the_engine test pins this list to sink_class.
