Expand description

propose plus one human-readable note per decision: which branch the delta took, why a call was NOT proposed (already known to a built-in table, filtered as noise, positive already alerts so the sink path is closed), and which candidates were produced.

The bundler prints these under FXDBG and stores them in the learn report (FXREPORT=<path>), so a family that teaches nothing can say why instead of the pipeline staying silent about it.
