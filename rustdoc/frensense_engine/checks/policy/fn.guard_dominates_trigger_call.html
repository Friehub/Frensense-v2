The bundler’s fact extractor consults the SAME guard model the scanner uses, so a corpus twin can teach a check whose negative suppresses the trigger dominantly (a bare guard(x); statement before the trigger, same block earlier or in a dominating block) even when no dataflow connects the guard’s value to the trigger’s arguments. Argument-nested calls (new Date() inside a where: { lt: ... } literal) are excluded, as their span lies inside the trigger’s argument span. Mechanism only; conclusions stay bundle data.
