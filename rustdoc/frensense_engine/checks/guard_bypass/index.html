Two seed mechanisms for guard/policy bugs taint analysis cannot see:

  1. Substring allowlist guards (redirect_challenge class): a guard that validates attacker input with x.includes(item) / indexOf(...) >= 0 over an allowlist is bypassable, https://evil.com?https://good.com contains the allowed substring. The mechanism is “validation by substring containment”; the corpus decides which callees/guards matter.

  2. Password KDF policy (weak_password class): a value flowing into a credential setter/hasher guarded by nothing but a fast digest wrapper. Mechanism: “hash-named call in a password-setting function”.
