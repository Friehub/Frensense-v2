Expand description

State for lowering one function body from tree-sitter nodes into a FunctionIR: the current block, lexical scopes, the heap-state variable and the loop stack.

Fields§

§spec: &'a dyn LanguageSpec

Language spec that classifies node kinds.

§source: &'a str

Source text the nodes are slices of.

§ir: FunctionIR

The IR under construction.

§env: Vec<FxHashMap<String, VarId>>

Lexical Environment mapping variable names to their VarId

§memory_var: VarId

The single mutable VarId representing the entire Heap State. It is mutated by Store/Call instructions. The SSABuilder will automatically version this into mem_1, mem_2, mem_3 and generate Memory Phis.

§facts: Option<&'a FactTable>

Optional learned fact table providing dynamic grammar overrides.

§nonlocal_decl: bool

Inside a static/extern declaration: the name has static storage (zero-initialised, or defined elsewhere), so it is not a function-local that can be read uninitialised and is not marked declared.

Lowers a unary operation.

++ and -- become a read-modify-write of the operand, & becomes an AddressOf and * a Dereference; any other operator becomes a UnaryOp recording the token (or neg when no token is found).

impl<'a> LoweringContext<'a>

Source

pub fn visit_node(&mut self, node: Node<'_>) -> Option<Operand>

Lowers one AST node into the current block, dispatching on the node’s role (a learned bundle role first, then the language spec).

Dispatch is by role (declaration, assignment, member access, call, loop, branch, match, return, try, operators, identifier, literal, composite), with a few grammar-specific cases the language spec answers (is_switch_statement, jsx_part, is_preproc_conditional, jump_kind). Function definitions are skipped, and any other node is lowered by walking its children.

Returns the operand holding the node’s value, or None for statements and nodes that produce no value.
