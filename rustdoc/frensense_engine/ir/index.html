The IR layer: pure data and the compiler frontend.

  • function, FunctionIR, Instruction, Operand, VarMetadata: the typed representation every analysis consumes.
  • lowering, tree-sitter AST → FunctionIR (via frensense-lang).
  • ssa, Memory SSA construction.
  • control, dominators / post-dominators / control dependence.

This layer knows nothing about taint, checks, or program graphs, it is the reusable compiler frontend.
