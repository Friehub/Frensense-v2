Phase 1: Intermediate Representation (IR)

This module defines the 3-Address Code and Control Flow Graph structures. It serves as the foundation for modern SSA-based dataflow analysis across dynamic, object-oriented, and systems languages.

NEW: Incorporates Memory SSA concepts. The heap is no longer a global state. Instead, memory mutations generate a new MemoryState (represented as a VarId), which perfectly tracks flow-sensitive object modifications over time.
