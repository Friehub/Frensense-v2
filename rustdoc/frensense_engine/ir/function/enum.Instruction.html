§span: Option<(usize, usize)>

Byte range of the expression that performs the write (the assignment, its member target, or the JSX attribute). The write is the statement a property-sink finding must point at: the stored value’s variable is defined somewhere else. None for stores a lowering synthesised without one source expression (object-literal fields, test fixtures).

CallStatic

Fields

§dest: Option<VarId>

Variable receiving the call’s return value, or None when the result is discarded.

§mem_out: VarId

Memory state after the call (calls may mutate memory).

§mem_in: VarId

Memory state the call executes in.

§func: String

Name of the called function as written at the call site.

§args: Vec<Operand>

Argument operands, in call order.

§arg_names: Vec<String>

Keyword/keyed argument names, parallel to args: entry i is the name of args[i], or empty when that argument is positional. Shorter than args (or empty) means the source language, or the lowered node, carries no names - callers must treat a missing entry as positional. See the args field documentation.

pub fn dest(&self) -> Option<VarId>

The value variable this instruction defines, if any.

Covers every instruction kind that produces a value: assignments, loads, calls (when the result is used), allocations, address-of, dereference, casts, aggregate extraction, unary/binary operations, await and yield. Memory-state outputs are not included; see Instruction::mem_out. This is the one definition of “what does this instruction define”; do not re-match the variants elsewhere, because a copy that forgets a variant silently drops findings on it.
