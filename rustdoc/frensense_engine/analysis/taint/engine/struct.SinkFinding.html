One explored sink argument with its verdict.

§function: String

Function in which the sink call lives.

§sink: String

Name of the sink call.

§arg_slot: usize

Zero-based position of the tainted argument as written in the call, not counting the receiver. usize::MAX (crate::graph::svfg::RECEIVER_ARG_INDEX) marks the receiver of a method call.

use frensense_engine::analysis::forward::ProgramSvfg;
use frensense_engine::analysis::taint::config::TaintConfig;
use frensense_engine::analysis::taint::engine::{BackwardTaintEngine, BackwardVerdict};
use frensense_engine::harness::lower_source;
use frensense_engine::ir::function::FunctionIR;

let src = r#"
declare const req: any
declare const db: any
export function run() {
  const q = req.body.x
  db.execute(q)
  q.execute("select 1")
}
"#;
let cfg = TaintConfig {
    sources: ["req.body".to_string()].into_iter().collect(),
    sinks: ["execute".to_string()].into_iter().collect(),
    sanitizers: Default::default(),
};
let owned = lower_source("t.ts", src, "ts").unwrap();
let irs: rustc_hash::FxHashMap<String, &FunctionIR> =
    owned.iter().map(|(k, v)| (k.clone(), v)).collect();
let prog = ProgramSvfg::new(&irs, &cfg);
let mut engine = BackwardTaintEngine::new(&prog, &cfg);
engine.run();

let slots_of = |v: BackwardVerdict| -> Vec<usize> {
    let mut s: Vec<usize> = engine
        .findings
        .iter()
        .filter(|f| f.verdict == v)
        .map(|f| f.arg_slot)
        .collect();
    s.sort();
    s
};
// `db.execute(q)`: `q` is argument 0, the receiver `db` is clean.
// `q.execute(..)`: the tainted value is the receiver, slot `usize::MAX`.
assert_eq!(slots_of(BackwardVerdict::Vulnerable), vec![0, usize::MAX]);
§alert: Option<SinkAlert>

Structured sink alert (present exactly when the slot is dangerous); None when the slot is a safe channel.

§verdict: BackwardVerdict

Verdict of the backward walk for this argument.

§finding_class: FindingClass

Shape classification of the finding ("idor" for access-control query payloads, "injection" for everything else). Consumers rank idor findings below Critical.

§role: SinkRole

What the sink does with its input, the primary severity signal.

§label: Option<String>

Semantic label slug for identity reporting (e.g. “prototype”, “ssrf”, “regex”).

§source_desc: Option<String>

Human description of the taint origin (the source access path, e.g. req.body.target), populated for Vulnerable verdicts.

§sink_span: Option<(usize, usize)>

Byte range of the sink call instruction in the source file, when the lowering recorded spans.

§path: TaintPath

Reconstructed source→sink chain (vulnerable findings only; empty otherwise, and empty when path capture is disabled).

§cut_reasons: Vec<&'static str>

Distinct reasons the backward walk was cut short on this argument (non-empty only for non-vulnerable verdicts). Each entry names a silent stop site: "guard", "value-const", "sanitizer", "unresolvable". Surfaces where a flow died under --explain; empty for vulnerable findings and for walks that simply exhausted their predecessors without hitting a source.

§suppressions: Vec<SanitizerSuppression>

Bundle sanitizer facts that silenced this argument, with family and class provenance. Empty when no fact cut the flow.

pub fn classify_from_cwe(&mut self, cwe: &str) -> bool

Fill in the vulnerability class from a corpus advisory CWE.

A bundle-learned sink carries no role or label of its own; the family that taught it declares a cwe:, and the bundle ships that CWE on the advisory pattern naming the sink. Applying it here classifies the finding from data every .frc already carries, so the replay gate and every reporting surface reach the same verdict without a bundle format change.

Returns true when the class was applied. A finding that already names a class is left alone: a built-in sink’s own vocabulary wins over the corpus advisory’s CWE.
