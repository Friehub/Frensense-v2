The committed fingerprint for this build. Recorded in every .frc the bundler writes and checked by the engine at load time.

When this value changes, so does every published bundle’s compatibility: bump BUNDLE_VERSION, regenerate the default pack, and rebuild any corpus bundle. docs/FORMATS.md carries the same rule in prose.
