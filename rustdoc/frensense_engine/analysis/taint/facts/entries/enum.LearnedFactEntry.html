Expand description

One learned fact as persisted in a .frc bundle. A tagged union over the three fact kinds, serde-friendly, decodable into a FactTable.

Variants§

§

Source

A taint source pattern: a call name or member-access path whose result carries attacker-controlled data. Merged into the scan’s crate::analysis::taint::config::TaintConfig::sources so bundles teach new frameworks without touching the built-in tables. Matches by full name or, for dotted entries, by last segment (same convention as sinks).

Fields

§pattern: String

Call name or member-access path whose result is attacker-controlled.

§package: Option<String>

Optional package qualification: when set, the entry only applies where this package is in scope.

§

Sink

A taint sink: a call that is dangerous when tainted data reaches one of its argument slots.

Fields

§call: String

Call name matched against the call’s last segment.

§package: Option<String>

Optional package qualification: when set, the entry only applies where this package is in scope.

§dangerous_args: BTreeSet<usize>

Dangerous argument slots; empty = all slots dangerous.

§binding_args_safe: bool

Whether non-dangerous slots are safe binding channels.

§kind: String

Whether this is a guard-style sanitizer; see SanitizerFact::guard_style.

Check

Install a corpus-verified non-dataflow check.

Fields

§rule: String

Stable rule id reported on a match.

§call: String

Trigger: a call whose last segment matches this name fires the rule.

§message: String

Advisory text shown to the user.

§severity: String

Advisory severity hint: "warning" or "critical".

§unless_guard: Option<String>

Fire only when this guard call is absent from the function (“trigger without enforcement”). None = presence-only.

§unless_range_check: Option<Vec<String>>

Fire only when the trigger’s argument is NOT compared against a literal bound with one of these operators (inline enforcement). None = no range qualification.

LanguageAmbiguousVerbs

HTTP-method verbs that are ambiguous as bare last-segment call names (routers app.get, maps m.set, http clients got.post, caches kv.put all share them). A dotted sink entry with one of these last segments arms receiver gating: the call only counts as a sink when its receiver root is a declared client root (the entry’s first segment). Phase 6.6: moved from LanguageSpec::known_ambiguous_verbs (a trait default no provider ever overrode) into the pack, one entry per language.

Fields

§language: String

Language key the entry applies to.

§values: Vec<String>

Verbs that are ambiguous as bare call names.

PolicyScoped

LanguageSinkGlobalOnly

Global-only builtin sink marker (appended last: bincode encodes the variant index first, so existing wire bytes keep decoding unchanged). Marks the language’s already-published LanguageSink entry with the global_only runtime flag: the bare call form is the sink, while a receiver-qualified call (engine.eval(x)) matches only once its origin resolves to a known package (WI-12).

Fields

§language: String

Language key of the sink entry being marked.

§call: String

Call name of the sink entry being marked.

§

IntegerOverflowUnboundedRule

Appended last (bincode encodes the variant index first, so existing wire bytes keep decoding unchanged): the SAME rule as IntegerOverflowRule with the unbounded-operand modality taught - the engine may fire on a size multiplication whose BOTH operands are unboundedly dynamic (malloc(rows * cols) CVE-190 shape). New intent must be added as its own trailing variant; never insert a variant before an established one.

Fields

§rule: String

Prover rule id.

§wrap_threshold: u128

Largest value the size computation may reach without wrapping; a computation whose proven maximum exceeds it is reported.

Source

pub fn finding_identities(&self) -> Vec<String>

Finding identities this fact’s scanner output is keyed by: checker rule ids and learned sink call names. The bundle-advisory join (BundlePattern::rules) goes through this, so a family’s [frensense] metadata can attach to the findings its facts cause. Entries whose findings use engine-internal rule ids (memory contracts, guard vocabularies, grammar) contribute none.

Source

pub fn apply(&self, table: &mut FactTable)

Insert this fact into a FactTable as Provenance::Learned (the bundle path: a corpus taught it).

Source

pub fn apply_with(&self, table: &mut FactTable, provenance: Provenance)

Insert this fact into a FactTable under an explicit Provenance. The embedded default pack (Phase 5.2) re-ships spec knowledge through the same entry type, so its provenance must stay Provenance::Spec instead of flipping to Learned.
