Expand description

Which hint table a LearnedFactEntry::Hints entry feeds. The hint vocabularies are flat string sets keyed by purpose (Phase 6 format extension): one entry kind, seven tables.

Variants§

§

UrlParam

super::FactTable::url_param_hints: a function parameter is URL-like.

§

UrlArg

super::FactTable::url_arg_hints: a guard argument is URL-ish.

§

UrlLiteral

super::FactTable::url_literal_hints: a literal is an absolute URL.

§

SecurityContext

super::FactTable::security_context_hints: a name marks security code.

§

AuthGuard

super::FactTable::auth_guard_hints: a call is an authentication check.

§

JwtAlgorithm

super::FactTable::jwt_algorithm_hints: an algorithm choice is security-sensitive.

§

CredentialContext

super::FactTable::credential_context_hints: an enclosing name marks credential context.

§

KdfReceiver

super::FactTable::kdf_receiver_hints: a receiver whose name marks a password-hashing library (a credential hashed through it is the intended use, not a policy violation). Appended last: bundles encode the variant position.

§

PreparedStatementPrefix

super::FactTable::prepared_statement_prefixes: a call whose last segment starts with one of these prefixes creates a bound-parameter statement handle (Prepare, prepareStatement, prepare_cached), so the handle’s later arguments are bindings rather than SQL. Appended last: bundles encode the variant position.

§

WeakHashDisclaimer

super::FactTable::weak_hash_disclaimer_tokens: an argument token that disclaims security use of a weak digest - a literal false flag marking the digest as a checksum or cache key. Appended last: bundles encode the variant position.

impl HintKind

Source

pub const ALL: [HintKind; 10]

Every variant, in wire order. .frc bundles encode the variant position, so this list is the serialization contract: appending a variant changes fact_vocabulary_fingerprint and therefore invalidates every bundle built before the change (rebuild the bundle, or keep the engine that built it).

Source

pub const fn index(self) -> usize

Wire discriminant of this variant. Exhaustive on purpose: adding a variant is a compile error here, which is the reminder to append it to Self::ALL (the ratchet test fails until it is).

Source

pub const fn name(self) -> &'static str

Stable name used in the vocabulary fingerprint and in diagnostics. Renaming a variant is a wire change too: the fingerprint catches it.
