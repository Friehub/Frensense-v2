The fact data types: sink signatures, sanitizer, check, policy and grammar facts.

Structs§

BufferBuiltinSpec
One buffer-manipulation builtin: which arguments are the destination buffer, the source data, and the length, so the spatial checker can verify write/read bounds against the tracked capacity.
GuardBypassFact
One corpus-verified guard bypass fact (containment callee or credential sink).
InsecureConfigRule
A string-literal insecure-configuration selector: a call whose argument literal selects an insecure mode regardless of algorithm. The literal selector and its advisory travel together so the check stays fact-driven end to end.
IntegerOverflowRule
An allocation-size integer-overflow prover rule (CWE-190 wrap -> CWE-680 undersized allocation). The engine owns the prover; this type owns the conclusion: rule id, wrap threshold, advisory.
KeySizeRule
A key-size rule: a generation call whose constant bit-length argument falls below the security floor. Value-aware: the argument may be a var whose lattice value is a provable constant, not just a bare literal.
LearnedCheckFact
One corpus-verified non-dataflow check, installed by a .frc bundle.
MemoryContractFact
One corpus-verified memory allocation or deallocation contract.
MemoryFuncSpec
One memory-function contract: what the call returns and which slots it consumes. Spec vocabulary only - bundle contracts travel as LearnedFactEntry::MemoryContract (owned strings).
PolicyFact
A corpus-verified co-occurrence policy: WHEN the trigger call appears in the scope, every requirement must ALSO be satisfiable in the scope, else the function violates the policy.
SanitizerFact
One learned/built-in sanitizer fact: a call that neutralizes taint.
SchemaPolicyFact
One corpus-verified tool/API schema policy fact.
SinkSignature
Per-argument classification for one sink API.
WeakCryptoFact
One corpus-verified weak cryptography rule.
WeakPrimitiveRule
A weak-primitive policy rule: a call whose string-literal selector (or bare name) selects a weak digest algorithm. Matches the two shapes real code uses: createHash('md5') (selector in an argument slot) and bare md5(data).

PolicyScope

TeachableNodeRole

Constants§

ALLOWLIST_SANITIZER_KIND
Sanitizer-kind label for guard-style sanitizers (the other half of the single producer dialect; see DEFAULT_SANITIZER_KIND).
DEFAULT_SANITIZER_KIND
Sanitizer-kind label for non-guard sanitizers: one dialect across every producer (spec seeding, the built-in table, bundle-learned facts). Advisory only; the engine cuts on every kind and branches on SanitizerFact::guard_style.
