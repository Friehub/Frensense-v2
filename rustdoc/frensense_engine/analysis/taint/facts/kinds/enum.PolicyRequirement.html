Expand description

A requirement that must hold for a policy’s trigger to be considered compliant.

Serde representation note: this enum must stay externally tagged (the default; no serde(tag = ...)). Internally-tagged enums require Deserializer::deserialize_any, which bincode 1.x - the .frc bundle codec - does not support: any bundle containing such a fact fails to deserialize at load time. External tagging serializes the variant name as a prefix, which bincode round-trips losslessly and JSON renders as {"GuardCall":{"call":"audit_log"}}.

BannedArgLiteral

The call’s argument at slot must NOT match any of values (case-insensitive comparison over string, boolean, or integer literals).

Fields

§slot: usize

Zero-based argument slot to inspect.

§values: Vec<String>

Literal values that are forbidden at that slot.

§

RequiredArgLiteral

The call’s argument at slot MUST match one of values (case-insensitive comparison over string, boolean, or integer literals).

Fields

§slot: usize

Zero-based argument slot to inspect.

§values: Vec<String>

Literal values, one of which the argument must be.

§

RequireArgKey

The call’s argument at slot must trace to an object construction carrying at least one of keys as an object-literal pair key (updateMany({ where: ... }): the where clause scopes which rows the bulk write touches). slot indexes the call’s argument list as the lowering records it (receiver excluded); usize::MAX matches ANY argument position. Traceability: fully-keyed object literals lower to Allocate(kind: Object) plus one StoreField per key, and the lowering records the pair keys on the composite var, so key presence is checkable in the IR without value analysis.

Fields

§slot: usize

Argument slot to inspect; usize::MAX matches any argument position.

§keys: Vec<String>

Object-literal keys, at least one of which must be present in the argument.

§

RequireNamedArgLiteral

The named argument name must be present and, when its value is a provable literal, carry one of values (case-insensitive).

Distinct from Self::RequiredArgLiteral: a keyword argument’s position moves when the caller omits earlier optional parameters (set_cookie("k", "v", path="/", secure=False) puts secure at slot 3, not 2), so a slot rule cannot express it correctly. Names arrive from the lowering’s arg_names (Python keyword_argument).

Absent name = violation (the caller did not set the flag at all). Present with an unresolvable value (a variable, a call result) is not a violation: the check proves literal violations only.

Appended last: bincode encodes the variant index first, so existing wire bytes keep decoding with their original indices.

Fields

§name: String

Name of the keyword argument.

§values: Vec<String>

Literal values the argument must carry (case-insensitive).

§

BannedNamedArgLiteral

When name is present as a named argument, its value must NOT match any of values (case-insensitive literal comparison).

Distinct from Self::RequireNamedArgLiteral: absent name is NOT a violation (allows framework defaults / benign calls to omit the flag without false positives).

Fields

§name: String

Name of the keyword argument.

§values: Vec<String>

Literal values the argument must not carry (case-insensitive).
