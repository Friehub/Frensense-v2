Expand description

Production table assembly for a set of extensions: the (empty) spec seed (tables_from_exts) + the default pack’s language-agnostic entries merged at Provenance::Spec, then its language-keyed sections installed for those extensions’ languages. This is byte-for-byte the order build_spec_tables (scan runner) and family_tables (fact bundler) use, exposed so tests can assemble tables that cannot drift from production.
