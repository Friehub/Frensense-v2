Source
Expand description

Everything a scan measured and used to throw away.

A scan used to answer one question - “are there findings?” - and discard the evidence behind the answer. BackwardStats was computed and dropped, lowering errors went to tracing::warn! with no subscriber installed so nobody ever saw them, every safety valve in the analysis truncated silently, and a file that could not be lowered was indistinguishable from a clean one. All four made a “Clean” report unfalsifiable: the reader had no way to tell “nothing here” from “we never looked properly”.

This module is the accounting. It is pure bookkeeping - no analysis decision reads it - and every counter here exists so the report can say how much of the program was actually analyzed, and what stopped it.
