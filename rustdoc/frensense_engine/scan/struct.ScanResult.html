Expand description

The result of one scan: sink findings of every verdict, checker findings, non-fatal errors and telemetry.

Fields§

§findings: Vec<SinkFinding>

All sink findings (every verdict); retain only findings whose verdict is Vulnerable to obtain the alert set.

A method call’s receiver is walked, because an object constructed from tainted data (new Package(taint)) hands that data to every method acting on it, but only a tainted receiver is reported: a clean or undecided receiver adds no finding, so an all-args signature (what FactTable::from_config builds) reports the same slots as one with explicit arguments.

use frensense_engine::analysis::taint::config::TaintConfig;
use frensense_engine::analysis::taint::facts::{FactTable, SinkSignature};
use frensense_engine::scan::scan;

let config = TaintConfig {
    sources: ["req.body".to_string()].into_iter().collect(),
    sinks: ["query".to_string()].into_iter().collect(),
    sanitizers: Default::default(),
};
let src = "declare const db: any\nexport function h(req: any) { db.query('SELECT ' + req.body.id) }\n";
let files = [("a.ts".to_string(), src.to_string(), "ts".to_string())];
let slots = |sig: SinkSignature| -> Vec<usize> {
    let mut facts = FactTable::from_config(&config);
    facts.sink_signatures.insert("query".into(), sig);
    let mut s: Vec<usize> = scan(&files, &config, &facts).findings.iter().map(|f| f.arg_slot).collect();
    s.sort();
    s
};
assert_eq!(slots(SinkSignature::with_args("query", &[0])), vec![0]);
// The receiver `db` is not an argument, and an all-args signature
// arms arguments only, so both signatures report the same slot.
assert_eq!(slots(SinkSignature::all_args("query")), vec![0]);
§located: Vec<LocatedFinding>

The same findings resolved to source locations (file/line/column).

§located_checker: Vec<LocatedChecker>

Non-dataflow policy violations (weak crypto, insecure config), resolved to file/line/column.

§checker: Vec<CheckerFinding>

Non-dataflow policy violations (weak crypto, insecure config). These have no taint path by definition; they are policy assertions over the API/constant choices in the lowered IR.

§errors: Vec<String>

Errors collected during the scan (for example files that failed to lower).

§analysis_incomplete: Vec<IncompleteFunction>

Functions analyzed in degraded form because their per-function work budget expired (see IncompleteFunction). Empty for a scan in which every function was analyzed fully.

§telemetry: ScanTelemetry

What the scan measured and what stopped it: phase timings, the files and functions that ate the time, every safety valve that fired, and how much of the input was actually readable. See crate::telemetry::ScanTelemetry.
