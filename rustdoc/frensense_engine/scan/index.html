Module scan 

Source
Expand description

The stable scan API (8.10): source text + facts → findings.

Everything downstream (CLI, bundler replay gate, benchmarks) calls this; nothing touches engine internals. The fact table is the teaching interface: built-ins from frensense-lang, merged with .frc bundle facts.
