frensense

Module identity 

Source
Expand description

Machine-readable build identity: one JSON object that answers “which engine, which fact vocabulary, which default pack, which schemas” for every artifact this binary produces.

frensense --version --json prints it; the release workflow asserts on it (so a published crate is never built from the wrong tree or the wrong pack); and the report producers embed its stable parts as a producer block so any finding can be traced back to the exact engine that emitted it.

This is Phase 6.0 of the roadmap: the single identity surface that the bundle-format (6.1) and report-schema (6.2) contracts hang off.
