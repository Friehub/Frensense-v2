frensense_scan_file - single-file scan tool for the MCP surface.

Exists because agents working in an editor loop need a focused question answered - “what did this file report?” - not a directory audit. frensense_audit reports findings tree-wide; frensense_scan_file answers only about the one file and labels every advisory with it, so the agent can associate fixes with the buffer it is editing.

Architecture split (same doctrine as the CLI): this module is a thin delivery adapter. All language knowledge lives in frensense-lang specs and the engine does all analysis via Engine::run(path); the only mechanism added here is the supported-file gate (is_supported, itself backed by the specs) and result shaping.
