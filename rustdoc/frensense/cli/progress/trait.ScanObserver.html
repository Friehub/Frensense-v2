Expand description

Receives scan progress from the scan runner.

This is a consumer-side type: the engine exposes the per-file capability (frensense_engine::scan::ProgramBuilder) and knows nothing about progress. Frontends with no UI use NoopObserver.

One step of scan progress.

completed counts files finished so far out of total; current is the file being lowered, when there is one; errors is the running count of files that could not be read or lowered.
