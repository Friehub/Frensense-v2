git queries behind --diff-only: which files changed since HEAD, and which lines of each one are new.

The gate answers one question — did this change introduce a finding? — so a finding at an unchanged line is pre-existing and belongs to the baseline (--compare-baseline), not to this diff. Scanning whole changed files made the gate fail on bugs nobody in this diff touched, which is both noise and an incentive to stop running it.
