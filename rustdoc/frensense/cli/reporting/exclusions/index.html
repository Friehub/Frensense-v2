Module exclusions

Report entry points that name the paths the default exclusion rules skipped.

The counts a report shows live on Coverage; the reasons and the sample travel in Exclusions. Keeping those entry points here means reporting.rs gains no length, and the compatibility entry points there remain byte-for-byte the same public API.
