pub fn bundle_rule_index(bundle: &LoadedBundle) -> String
Expand description

One line per learned rule a bundle publishes: id, kind+severity, first line of its message. Printed by frensense explain --list-rules -b <bundle> so bundle-taught ids are as discoverable as built-in ones.
