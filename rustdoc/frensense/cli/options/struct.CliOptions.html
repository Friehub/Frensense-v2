Expand description

CLI options for the deterministic dataflow compiler scan.

#[non_exhaustive]: an evolving options DTO. New flags (e.g. explain in 0.8.0) are added as minor releases; construct via super::parse_options, not literals.

§paths: Vec<PathBuf>

Positional scan target paths (files or directories).

§format: String

Report format: “text”, “json”, “sarif”, “github”.

§output_path: Option<PathBuf>

Optional output file to write the report to.

§is_strict: bool

Fail with exit code 1 if any findings are found.

§severity_filter: Option<Severity>

Minimum severity floor: critical, high, medium, warning, low, info. Default: warning.

§language_filter: Option<String>

Language filter (e.g., rust, go, typescript, javascript, python, c).

§corpus_bundle_path: Option<PathBuf>

.frc bundle providing learned facts and advisory patterns.

§emit_baseline_path: Option<String>

Save current findings as a baseline JSON artifact.

§compare_baseline_path: Option<String>

Compare findings against a baseline and fail on new findings.

§diff_only: bool

Only scan files modified relative to git HEAD.

§explain: bool

Record every silent sink argument (why the engine stayed quiet).

§show_suppressed: bool

Show flows silenced by a bundle sanitizer fact, with the fact’s family and class provenance (--show-suppressed).

§explain_json_path: Option<PathBuf>

Write the --explain records as JSON to this file (implies --explain).

§show_flows: bool

Include the taint-path flow (source→sink SSA steps) in the text observation. JSON/SARIF always carry the path (taint_steps / SARIF codeFlows); --show-flows additionally embeds it in the text observation for terminal reports.

§profile: Profile

Precision profile: default (stable), recommended (stable + beta), or strict (all tiers, including hygiene and experimental).

§enable_hygiene: bool

Report code hygiene rules (e.g. function complexity) under any profile.

§max_complexity: Option<usize>

Maximum cyclomatic complexity ceiling before emitting function_complexity.

§fail_on_incomplete: bool

Exit with code 2 if the scan was incomplete, degraded, or had errors.

§profile_output: Option<PathBuf>

Destination path to write profiling/telemetry JSON.

§trace: bool

Initialize tracing subscriber for spans and logs.

§no_progress: bool

Disable real-time progress bar and updates.

§disable_rules: Vec<String>

Rule ids to suppress (--disable-rule, repeatable or comma-separated).

§only_rules: Vec<String>

When non-empty, report only these rule ids (--only).

§config_path: Option<PathBuf>

Project config file (--config); defaults to .frensense.toml in cwd.

§include_dirs: Vec<String>

Directory names to scan even though a default rule skips them (--include-dir, repeatable or comma-separated).

§no_default_excludes: bool

Scan without the default directory, size and minified-file exclusions (--no-default-excludes).
