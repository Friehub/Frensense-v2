Struct Engine

pub struct Engine { /* private fields */ }
Expand description

The scan engine.

Configuration is minimal by design: the analysis knowledge lives in the language specs (frensense-lang) and the .frc bundle’s learned facts, not in knobs on this struct.

pub fn run_observed( &mut self, root: &Path, observer: &mut dyn ScanObserver, ) -> Result<Vec<Advisory>>

Scan a directory tree or a single file, reporting progress to observer.

The engine has no progress API: this runner drives frensense_engine::scan::ProgramBuilder one file at a time and forwards each frensense_engine::scan::FileReport as a progress step. A frontend with no UI passes crate::cli::NoopObserver via run.

pub fn take_coverage(&mut self) -> Coverage

Take what the most recent run covered: files found versus analyzed, sink sites inspected, which files yielded none, and which sites it left undecided. A consumer that reports “no findings” must consult this, or it cannot tell “inspected, no finding” from “nothing recognized”.
