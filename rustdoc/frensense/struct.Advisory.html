A single finding, rendered compiler-style: where, what, why, how to fix.

§title: String§file_id: FileId§file_path: String§severity: Severity§confidence: f64§observation: String§impact: String§improvement: String§line: u32§end_line: u32

Last line of the finding’s span (defaults to line). Multi-line findings, an allowlist definition, a large expression, report the full extent so consumers and scorers can match against any line the finding actually covers.

§column: u32§start_byte: u32§end_byte: u32§original_content: String§enclosing_symbol: Option<String>§fingerprint: String§rule_id: String

Stable rule id (taint.sql-injection, check.weak-hash, policy.<id>). Never finding-specific text: reporters group, suppress and trend by this. Empty only for advisories built outside the engine; use Advisory::rule_id for a guaranteed value.

§requires_human: bool§tags: Vec<String>§tier: RuleTier

Precision tier governing profile filtering.

§taint_steps: Vec<(String, Option<(String, usize)>)>

Per-step descriptions of the taint flow (source→sink) plus the byte offset of each step, when the engine captured a path. Empty for non-dataflow findings. Rendered into SARIF codeFlows.
