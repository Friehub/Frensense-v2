FrensenseCode scanning that shows its work

A deterministic static analyser that follows untrusted input through your code and reports each path from source to dangerous call. Open source, one binary, no network.

Get started
Install
GitHub

Exact taint paths

Every finding comes with the path the data took, with file positions, so you can check it yourself. The same input always gives the same result.

Teachable engine

Label a vulnerable example and its fixed twin, and the bundler learns the missing sources, sinks and sanitizers into a .frc bundle you can load.

Multi-language

TypeScript, JavaScript, Python, Go, Rust and C, with early Vue support. Each language is a small tree-sitter provider on a shared engine.

Memory safety

Use-after-free, double-free, out-of-bounds and leak checks, built on allocation summaries and value tracking.

Built for agents

MCP and LSP servers are built into the same binary, so an AI agent or an editor can check code with the same engine. Read why in our essay.

Open core

The engine is GPL-3.0 free software. Knowledge bundles extend what it can detect, and commercial licences are available.
