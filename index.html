FrensenseDeterministic security engine

Static analysis without the rules. Frensense lowers every file to a program graph and reports exact source-to-sink taint paths. Findings are reachability queries, not guesses.

Exact taint paths

Every finding comes with the concrete source-to-sink path through the program graph, with file positions. Not a confidence score.

Teachable engine

Label a vulnerable example and its fixed twin in the corpus, and the bundler learns source, sink, sanitizer facts and policies into a checksummed .frc bundle.

Multi-language

TypeScript, JavaScript/TSX, Python, Go, and Rust, with per-language providers (Oxc for JS/TS, rust-analyzer HIR for Rust).

Memory safety

Use-after-free, double-free, and out-of-bounds checkers built on interprocedural allocation summaries and an abstract value lattice.

Built for agents

MCP and LSP servers built into the frensense CLI. Read why frontier AI needs deterministic oracles in our research essay.

Open core

The engine is GPL-3.0 free software; .frc knowledge bundles carry the detection knowledge. Commercial licences available.
