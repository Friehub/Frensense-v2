A deterministic static analyser that follows untrusted input through your code and reports each path from source to dangerous call. Open source, one binary, no network.

The Linux build is linked against glibc from Ubuntu 24.04, so it needs glibc 2.39 or newer: it will not run on musl-only systems such as Alpine, or on older distributions. Use cargo install frensense there, or npx @friehub/frensense with Node installed.

Other platforms are on the releases page. No install needed - run npx @friehub/frensense .. Every surface shares one engine and one finding-ID scheme. Full options in the installation guide. Building on the crates? Browse the Rust API docs.
