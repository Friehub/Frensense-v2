Install ​

Frensense is one binary named frensense. Pick the route that fits your machine, then run frensense --version to check it worked.

RouteNeedsCommand
npmNode.js 18 or newernpm install -g @friehub/frensense
No installNode.js 18 or newernpx @friehub/frensense .
CargoRust 1.95 or newercargo install frensense
Release downloadnothingsee below

npm ​

The npm package carries prebuilt binaries, so you do not need a Rust compiler. It supports Linux x64, macOS (Intel and Apple Silicon) and Windows x64.

bash
npm install -g @friehub/frensense
frensense --version

The frensense command from npm is a small launcher around the native binary. Every subcommand (watch, mcp, lsp, ...) works the same way.

Cargo ​

bash
cargo install frensense

This compiles the binary and puts it in ~/.cargo/bin. It needs Rust 1.95 or newer, and takes a few minutes.

Release download ​

Each GitHub release attaches one binary per platform, named after its Rust target:

PlatformFile
Linux x64frensense-x86_64-unknown-linux-gnu
macOS Intelfrensense-x86_64-apple-darwin
macOS Apple Siliconfrensense-aarch64-apple-darwin
Windows x64frensense-x86_64-pc-windows-msvc.exe

There is no Linux arm64 build yet. On Linux x64:

bash
curl -L -o frensense \
  https://github.com/Friehub/frensense-v2/releases/latest/download/frensense-x86_64-unknown-linux-gnu
chmod +x frensense
sudo mv frensense /usr/local/bin/

Releases are built by a GitHub Actions workflow that also produces a SLSA provenance file (*.intoto.jsonl) for the binaries. You can check a download against it with slsa-verifier.

Check the install ​

bash
frensense --version     # prints: frensense 0.8.0
frensense --help        # lists every flag and subcommand

If a scan ends with Status: Failed analysis and a warning about "unsupported or absent source input", the folder holds no supported files. Try it inside a project that has a .py, .ts, .js, .go, .rs or .c file.

Build from source ​

Only needed if you want to change the engine:

bash
git clone https://github.com/Friehub/frensense-v2.git
cd frensense-v2
cargo build --release

The binary is target/release/frensense. See CONTRIBUTING.md before opening a pull request.
